# Demo dataset

`ownership-radar-demo.sqlite` is a **synthetic** dataset generated by
`scripts/build_demo_dataset.py`. It is small (~330 KB), deterministic
(same logical digest on every rebuild) and contains **no CNMV raw
documents** — every `raw_sha256` is the hash of a synthetic
placeholder.

Issuer identities are real public facts (NIFs, ISINs, names of
Banco Santander / BBVA); every notice, transaction, position and
relation is **invented** for demonstration. Do not treat demo rows
as regulatory information.

Rebuild:

```bash
python scripts/build_demo_dataset.py          # -> this file
```

Cases covered: single + multi-transaction NOD, significant-holding
disclosure, treasury operations vs resulting position, ANNULS chain
(observed later — known_at transition), ambiguous ANNULS,
cross-issuer notices, a disappearance streak, BACKFILL vs
INCREMENTAL/RECONCILIATION feed separation.
