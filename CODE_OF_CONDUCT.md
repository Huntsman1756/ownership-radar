# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, be constructive, assume good faith.
Harassment, personal attacks and publishing private information are not
acceptable.

## Enforcement

Report unacceptable behaviour through a **private** contact channel listed
on the maintainer's GitHub profile. Do not put sensitive conduct reports,
personal information or evidence that could identify a reporter in a public
issue.

If no private contact channel is available, a minimal public issue may ask
for private contact without describing the incident. Reports and enforcement
decisions should be handled as confidentially as the available channel
permits.

## Scope

This code applies to all project spaces — issues, pull requests, reviews and
any communication about the project.
