# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, be constructive, assume good faith.
Harassment, personal attacks and publishing private information are
not acceptable.

## Enforcement

Report unacceptable behaviour to the project maintainer through the
repository's issue tracker (marked as a conduct report) or via the
contact listed on the maintainer's GitHub profile. Reports are
handled confidentially.

## Scope

This code applies to all project spaces — issues, pull requests,
reviews and any communication about the project.
