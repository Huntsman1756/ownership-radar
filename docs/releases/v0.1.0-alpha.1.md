# Release notes — v0.1.0-alpha.1

**Ownership Radar ES — first public pre-release.**
Production-data alpha / public developer preview. Not stable; not
production-graded software — the *dataset semantics* are
production-validated.

## What is ready

- Acquisition, evidence and notice core (G1): typed crawl runs,
  immutable content-addressed raw captures, append-only observations.
- Semantic parsers (G2/G3): NOD insider transactions, significant
  holdings, treasury operations/stock — template-aware, fail-closed.
- Bitemporal ledger (G4): deterministic derivation, two explicit
  time axes, annulment chains with explicit AMBIGUOUS.
- Production scale (G5): `itf2026-v1` universe — 60 issuers, 34,981
  notices, 158,083 events, 179,129 feed items; deterministic
  ledger digest.
- Public surface (G6): read-only Python API + CLI (json/jsonl/atom),
  incremental replayable feed with stable IDs and versioned cursors.
- Release engineering (R1): demo dataset, runnable examples, CI,
  docs, audits.

## What is experimental

- The **public API shape** — tested contract, but names may change
  before 1.0 (recorded in CHANGELOG).
- The **feed item taxonomy** — stable IDs promised; new item types
  may appear in later releases.
- Coverage beyond `itf2026-v1` — the 60-issuer universe is the only
  validated denominator.

## Dataset / universe

Production dataset is **not shipped**. The repository ships a
deterministic synthetic demo (~330 KB,
`python scripts/build_demo_dataset.py`) that exercises the full
public surface. Raw CNMV documents are never redistributed
(DATA-NOTICE.md).

## API stability expectations

`0.1.0a1` / `v0.1.0-alpha.1`: public API exists and is contract-tested
(133 tests); breaking changes remain possible before 1.0 and will be
documented in CHANGELOG.md with migration notes when needed.

## Known limitations

See README "Known limitations" — most relevant for consumers:

- Coverage is a 60-issuer ITF universe, not "all Spanish issuers".
- Historical completeness is not externally proven per surface.
- Feed is incremental *as ingested* — not real-time.
- Ambiguous ANNULS and unsupported templates fail closed by design.

## Next likely work

Wider issuer universe, legacy/OCR document support, additional CNMV
families, packaging to PyPI, a read-only web layer — ordered by real
use, not committed for 0.1.x.
